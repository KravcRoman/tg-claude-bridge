# tg-claude-bridge

Локальный мост между сессиями Claude Code (десктоп, Windows) и Telegram.

Когда параллельно работает несколько сессий, за ними неудобно следить с экрана. Бот присылает в Telegram только важное: сессия закончила ход, задала вопрос, упала с ошибкой или просит разрешение. Из чата можно посмотреть список сессий, открыть последние реплики любой из них и ответить агенту.

Чистый stdlib Python 3.10+, без сторонних зависимостей.

## Возможности

- Уведомления по событиям хуков: ✅ готово, ❓ вопрос, 🔴 ошибка, 🔔 запрос внимания, 🔐 запрос разрешения.
- Краткое содержание последнего ответа вместо полного текста.
- `/status`: дайджест по пяти последним сессиям с их состоянием.
- Просмотр диалога: последние два вопроса и два ответа выбранной сессии.
- Вопросы агента с вариантами (`AskUserQuestion`) приходят с кнопками выбора.
- Свои имена для сессий (`/name`), режим «только важное» (`/level important`), тихие часы.
- Ответ в сессию из Telegram (опционально, по умолчанию выключено).

## Как это устроено

```
Claude Code (десктоп)
   │  хуки Stop / Notification / PermissionRequest
   ▼
hook.py ──HTTP 127.0.0.1──► bot.py
                              ├─ читает транскрипты ~/.claude/projects/<проект>/<uuid>.jsonl
                              ├─ Telegram long polling: уведомления, кнопки, команды
                              ├─ следит за вопросами агента без ответа
                              └─ завершается сам, когда десктоп закрыт
```

- `hook.py` вызывается хуками Claude Code и пересылает событие боту. Если бот не запущен, хук молча выходит и ничего не копит.
- `bot.py` определяет состояние сессии по транскрипту: последняя реплика, незавершённые вызовы инструментов, вопрос без ответа.
- Бот работает только пока открыт десктоп и только после ручного включения.

## Безопасность

- Бот отвечает одному владельцу: `owner_chat_id` закрепляется первым `/start`, остальные чаты игнорируются.
- HTTP-приёмник слушает только `127.0.0.1` и проверяет общий секрет в заголовке.
- Путь к транскрипту из события принимается, только если он лежит внутри каталога проектов Claude; идентификатор сессии проверяется по формату UUID.
- Токены и состояние лежат в `config.json` и `state.json`, оба файла в `.gitignore`.

## Установка

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Запусти установщик. Он запишет `config.json` и добавит хуки в `~/.claude/settings.json`, не трогая существующие, с резервной копией рядом:
   ```powershell
   python install.py <ТОКЕН_ОТ_BOTFATHER>
   ```
3. Включи бота:
   ```powershell
   python enable.py
   ```
4. Напиши боту `/start` в Telegram.

Выключить: `/stop` в Telegram или `python disable.py`.

## Команды

| Команда | Что делает |
|---|---|
| `/status` | Пять последних сессий и их состояние |
| `/name <имя>` | Назвать активную сессию |
| `/level all\|important` | Все уведомления или только вопросы, ошибки и запросы внимания |
| `/stop` | Выключить бота |
| `/help` | Справка |

## Настройки `config.json`

| Поле | Значение |
|---|---|
| `telegram_bot_token` | Токен от @BotFather |
| `owner_chat_id` | Заполняется при первом `/start` |
| `listen_port` | Локальный порт для событий от хука, по умолчанию 8787 |
| `event_secret` | Общий секрет хука и бота, генерируется установщиком |
| `notify_level` | `all` или `important` |
| `quiet_hours` | Например `[23, 8]`: обычные уведомления молчат, вопросы и ошибки проходят |
| `desktop_process_marker` | Подстрока пути процесса десктопа |
| `desktop_grace_seconds` | Через сколько секунд после закрытия десктопа бот выходит |
| `summarize_with_llm` | Пересказ длинных ответов через `claude -p`, по умолчанию `false` |
| `inbound_enabled` | Ответы в сессию через `claude -p --resume`, по умолчанию `false` |

## Про вызовы Claude из бота

По умолчанию бот не делает ни одного вызова Claude: уведомления, статусы и просмотр диалога строятся только на хуках и чтении транскриптов.

Опции `summarize_with_llm` и `inbound_enabled` запускают headless CLI. Включай их осознанно:

- Headless-вызов создаёт новую сессию, у которой тоже срабатывает хук `Stop`. Без защиты бот начинает уведомлять сам себя и зацикливается. Здесь это закрыто переменной окружения `TG_BRIDGE_INTERNAL` и маркером в тексте запроса, но любую доработку этих мест проверяй на петли.
- Для автоматических вызовов используй API-ключ, а не учётные данные личной подписки.
